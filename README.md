# PVS G1 EDU · presentación interactiva

Página web interactiva con el robot G1 EDU (29 GDL, manos Inspire de 5 dedos) en 3D

## Créditos
- Modelo 3D: archivos URDF de Unitree Robotics (repositorio unitree_ros), licencia BSD-3.
- Librería 3D: three.js r128, licencia MIT.
- Motores, placas y sensores internos: ilustraciones agregadas para la presentación.
